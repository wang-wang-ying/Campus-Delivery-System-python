# Campus-Delivery-System-python
校园跑腿平台是一个前后端分离的多端管理系统，用于管理校园内的跑腿服务业务。系统覆盖跑腿任务管理、跑腿员管理、订单管理、用户管理、公告管理、数据统计和系统管理七大业务模块，实现了从任务发布、任务审核、跑腿员接单、订单配送、订单确认到数据统计的完整业务流程。  
系统后端采用 Python FastAPI 框架，管理端前端采用 Vue3 技术栈，用户端采用 uni-app Vue3 技术栈，数据库使用 MySQL。  
此外，本系统还集成了权限控制模块，支持根据不同角色分配不同权限，确保不同用户只能访问和操作自己权限范围内的数据。
### 1、系统功能

⭕ 管理后台

· 登录

· 首页

· 跑腿任务管理：任务列表 | 任务审核 | 任务分类

· 跑腿员管理：跑腿员列表 | 入驻审核

· 订单管理：订单列表

· 用户管理：用户列表

· 公告管理：公告列表

· 数据统计：任务统计 | 订单统计

· 系统管理：账号管理 | 角色管理 | 菜单管理

⭕ 用户端前台（手机端）

登录/注册 | 首页 | 任务大厅 | 发布任务 | 任务详情 | 我的任务 | 我的订单 | 订单详情 | 跑腿员入驻 | 平台公告 | 我的 

### 2、技术栈与工具
本项目采用稳定且广泛应用的技术栈，结合 Python 后端开发与 Vue 前端开发，确保开发流程清晰、系统稳定。

技术选型

· 后端：Python 3.12 + FastAPI

· 数据库：MySQL 8.0

· ORM：SQLAlchemy

· 管理端前端：Vue 3 + Element Plus

· 用户端前端：uni-app + Vue 3

· 开发工具：VSCode / PyCharm / HBuilderX
